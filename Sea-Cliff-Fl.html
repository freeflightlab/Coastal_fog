2.5D CFD slices · wind · fog · heat · ridge lift

Sea cliff flow, slice by slice

A small flow solver runs in this page. It computes wind, turbulence, temperature, humidity and fog in a vertical slice across a coastal cliff, including the wind along the coast. Change the cliff and the air, load a real terrain profile, watch fog form and burn off, and save the setup as a JSON file.

One file of about 300 KB that runs in any modern browser, offline too, starting from the setup on screen.

Along the coast

Each slice is solved on its own, as if that cross-section ran unchanged up and down the coast, and the slices are then placed side by side. Particles drift between them with the along-coast wind. Add slices to the north or south with different cliffs, or move the slice along the coast to blend the cliffs on either side.

        The saved file

        One JSON file holds a whole setup: the incoming air, the sea and land, fog physics and one or more slices along the coast. Values are SI, with the unit in each name. A slice is either a cliff built from the shape controls or a list of points, so elevation profiles taken from topographic data can be loaded the same way.
